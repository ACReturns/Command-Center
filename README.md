# Command-Center
A local build tool for individuals to Update/ Patch and launch local builds while also selected the specific server they want to launch the game on. 
Focusing on Both Development and Live  Environments. This will also handle detecting what test/ staging servers are currently active/ down to make
testing easier to know what you want to launch. Utilizing C# & WPF this tool is mainly being used at Nexon for launch9ing & testing Maplestory/ Maplestory Classic
Along with other projects down the road. This will support a progress bar to to give the user feedback as far as what the status is currenlty for
the build they are currently working with.
